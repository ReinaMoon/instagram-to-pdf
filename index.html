Instagram to PDF web

Paste a link to a public Instagram post (single image or carousel). Run it in the cloud via GitHub Actions and download every image, or one combined PDF.

Runs on your own GitHub Actions minutes.

GitHub Personal Access Token

This page calls the GitHub REST API directly from your browser to start the workflow and check its progress. It never leaves your browser except to talk to GitHub, and it is saved only in this browser's local storage.

Create a token with access to only this repository:

  1. Go to GitHub › Settings › Fine-grained tokens
  2. Under "Repository access", choose Only select repositories and pick this repo
  3. Under "Permissions › Repository permissions", set Actions to Read and write
  4. Generate the token and paste it below
